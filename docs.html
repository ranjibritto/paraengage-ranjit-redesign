ParaEngage for developers

One API key, one base URL and one wallet across voice, messaging, video and AI. Everything on this page is a draft reference built to be implemented. Values are illustrative until Parahit publishes the production spec.

BASE URL https://api.paraengage.com/v1 JSON · HTTPS · UTF-8

Quickstart: first call in 5 minutes

This walkthrough bridges your agent and a customer through a masked ParaEngage number and delivers the call record to your webhook.

  1. Create an account and verify your businessSign up at the console. Verification is instant for GST-registered businesses and adds 1,000 free credits to your wallet.
  2. Get your API keyConsole → Build → API keys. Test keys start with pe_test_ and never charge the wallet. Live keys start with pe_live_.
  3. Buy or pick a numberNumbers → Buy. Or use the sandbox number +91 80 0000 0000 with a test key.
  4. Make the call 
    curl -X POST https://api.paraengage.com/v1/calls \
  -H "Authorization: Bearer $PARAENGAGE_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "from": "+918000000000",
    "agent": "+919800000001",
    "customer": "+919700000002",
    "record": true,
    "webhook_url": "https://yourcrm.in/hooks/paraengage"
  }'
    import ParaEngage from "@paraengage/sdk";
const pe = new ParaEngage(process.env.PARAENGAGE_API_KEY);

const call = await pe.calls.create({
  from: "+918000000000",
  agent: "+919800000001",
  customer: "+919700000002",
  record: true,
  webhookUrl: "https://yourcrm.in/hooks/paraengage"
});
console.log(call.id, call.status); // call_01HX..., "ringing"
    from paraengage import ParaEngage

call = pe.calls.create(

print(call.id, call.status)

  5. Read the response 
    {
  "id": "call_01HXK3M9Q2R7",
  "status": "ringing",
  "from": "+918000000000",
  "agent": "+919800000001",
  "customer": "+919700000002",
  "record": true,
  "created_at": "2026-10-04T09:30:12+05:30",
  "estimated_cost": { "currency": "INR", "per_minute": 0.75 }
}
  6. Receive the webhookWhen the call ends, ParaEngage POSTs a call.completed event to your URL. See Webhooks for the payload and signature check.

Authentication

Every request carries a bearer token. Keys are created per workspace in the console and can be scoped to products.

Authorization: Bearer pe_live_9f3a7c...   # live key, charges the wallet
Authorization: Bearer pe_test_2b81e4...   # test key, sandbox only, never charges
Key typePrefixWhat it can do
Livepe_live_Real calls and messages. Billed from the wallet.
Testpe_test_Sandbox numbers only. Returns realistic responses and fires webhooks with "test": true.
Restrictedpe_rk_Live, limited to named products (for example SMS only) and optional IP allowlist.
Never ship a live key in a browser or mobile app. Use the Chat Bot widget token or a server-side proxy.

Test mode and sandbox numbers

With a test key, these numbers return fixed outcomes so you can exercise every branch of your code.

NumberBehaviour
+919700000002Answers after 3 seconds. Webhook: call.completed, 42 s duration.
+919700000003Busy. Webhook: call.failed, reason busy.
+919700000004No answer after 30 s. Reason no_answer.
+919700000005Messages: delivered then read after 5 s.
+919700000006Messages: undelivered, reason dnd.

Errors and rate limits

Errors use standard HTTP codes with a machine-readable body. Rate limits are per key and returned in headers.

{
  "error": {
    "code": "insufficient_balance",
    "message": "Wallet balance is ₹12.40. This call needs at least ₹50.00.",
    "doc_url": "https://docs.paraengage.com/errors#insufficient_balance",
    "request_id": "req_01HXK..."
  }
}
CodeMeaning
400 invalid_requestA field is missing or malformed. error.param names it.
401 unauthorizedMissing or revoked key.
402 insufficient_balanceTop up the wallet or enable auto-recharge.
403 product_not_enabledTurn the product on in the console. Price is shown there first.
404 not_foundNo object with that id in this workspace.
422 template_not_approvedWhatsApp or DLT template is pending or rejected.
429 rate_limitedRetry after Retry-After seconds. Default 50 requests/second per key.

API reference

All endpoints are relative to https://api.paraengage.com/v1. List endpoints are cursor-paginated with limit and starting_after. Amounts are in INR with two decimals.

Click to Call: create a call

POST /calls
ParameterTypeDescription
fromrequiredstringA ParaEngage number in your workspace, E.164. Shown to both parties.
agentrequiredstringAgent's mobile, or an agent id (agt_...) to ring the browser dialer.
customerrequiredstringCustomer number, E.164.
recordoptionalbooleanRecord the call. Default false. Recording billed per minute.
ring_timeoutoptionalintegerSeconds to ring each leg. 5 to 60. Default 30.
webhook_urloptionalstringOverrides the workspace webhook for this call.
metadataoptionalobjectUp to 20 key-value pairs, echoed in every webhook. Use for CRM ids.

Legacy console fields map as follows: TID → id, CID → customer, FPN → from, SPN → agent, BID → metadata.batch_id, BST → status.

Webhooks

Set a workspace webhook in Console → Build → Webhooks, or per request with webhook_url. Every delivery is a POST with a JSON body, signed with your webhook secret. The console has a "Send test webhook" button for every event type.

EventWhen
call.ringing, call.answered, call.completed, call.failedClick to Call, IVR and Robo Call legs
message.sent, message.delivered, message.read, message.failedWhatsApp, SMS, RCS, Email
message.receivedInbound WhatsApp, RCS or SMS reply
otp.verified, otp.expiredOTP API
conversation.completed, conversation.handoverAI Agent, Voice Bot, Chat Bot
wallet.low_balance, wallet.rechargedWallet
POST https://yourcrm.in/hooks/paraengage
X-ParaEngage-Signature: t=1791105000,v1=5f8d2c...
X-ParaEngage-Event: call.completed

import crypto from "crypto";

function verify(rawBody, header, secret) {
  const [t, v1] = header.split(",").map(p => p.split("=")[1]);
  const expected = crypto.createHmac("sha256", secret).update(t + "." + rawBody).digest("hex");
  return crypto.timingSafeEqual(Buffer.from(expected), Buffer.from(v1));
}

Respond with any 2xx within 10 seconds. Failed deliveries retry at 1, 5, 30 and 120 minutes, then move to the dead-letter list in the console.

Glossary

WorkspaceOne company account with its own wallet, keys, numbers and agents.
Masked callA bridged call where neither party sees the other's number, only the ParaEngage number.
DLTTRAI's Distributed Ledger Technology registry for SMS senders and templates in India.
Conversation (WhatsApp)A 24-hour window opened by a template or customer message, billed by category.
HandoverAn AI agent passing the conversation to a human with transcript and context attached.
